Setup & plugins

Install the daemon, connect your account, and check supported harnesses.

Set up the daemon

1. Install the daemon

One command installs the daemon, logs you in, and starts tracking. Works on Windows, macOS, and Linux.

# macOS / Linux
curl -fsSL <this site>/install.sh | sh -s -- YOUR_API_KEY

2. Wrap any CLI agent (agent time excluded)

goodvibes wrap --harness claude-code -- claude -p
goodvibes wrap --harness codex --mode prompt_vtt -- codex

3. Submit a verifiable audit bundle

goodvibes bundle --project MY_PROJECT --program "YSWS" --upload
